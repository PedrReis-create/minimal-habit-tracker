# Minimal Habit Tracker

A dark, minimal habit tracker inspired by the attached reference.

## Stack

- React
- Vite
- CSS
- Lucide React
- `localStorage` for persistence

## Features

- GitHub-style yearly heatmap for every habit
- Click a day to toggle completion
- Current streak, best streak and annual completion percentage
- Add, edit and delete habits
- Habit color, emoji and weekly target
- Calendar / Statistics / Manage views
- JSON export and import
- Local persistence
- Responsive layout

## Run

```bash
npm install
npm run dev
```

Then open the URL shown by Vite.

## Build

```bash
npm run build
```

No backend is required. Data is stored in the browser's `localStorage`.
